# Privacy Policy — Filelio: File Manager

**Package:** `com.filelio.filemanager`  
**Effective date:** September 25, 2026

## 1. Overview
Filelio: File Manager (“Filelio”, “the app”, “we”, “us”, or “our”) is an Android file-management application designed to help users browse, organize, search, copy, move, rename, compress, extract, share, restore, and delete files stored on their device.

The current version of Filelio processes file information locally on the device and does not automatically upload a user's files or file contents to our servers.

## 2. Information We Collect
The current version of Filelio does not require an account and does not automatically collect or transmit personal information to us. File and storage information used by the app is processed locally to provide file-management features.

Filelio does not include an Internet permission in the current app build, so the app itself does not use a network connection to send files or analytics data to us.

## 3. File and Storage Access
Filelio's core purpose is file management. To provide this functionality, the app may request broad storage access, including Android's “All files access” permission where supported and permitted by the operating system.

This access is used for user-requested file-management features such as browsing, searching, copying, moving, renaming, creating folders, ZIP/Unzip, storage analysis, Favorites, Recents, and Recycle Bin.

Filelio does not use storage access to secretly upload, sell, or commercially profile the user's files.

## 4. Sharing Files
Filelio includes a user-initiated Share feature. When the user chooses to share a file, Android's system sharing interface may provide the selected file to the app or service chosen by the user.

Any data handling by the receiving app or service is governed by that third party's privacy policy. Filelio does not automatically share files without the user's action.

## 5. Recycle Bin and Local App Data
Filelio may keep local records required for Favorites, Recents, and Recycle Bin. These remain on the device until removed, restored, permanently deleted, cleared by the user, or removed with the app.

## 6. Storage Analyzer and Duplicate Finder
Storage analysis and duplicate-file detection are performed locally. The app may inspect file names, paths, sizes, dates, and file content as necessary to identify duplicates or calculate storage usage. This information is not automatically transmitted to us.

## 7. Internet, Advertising, and Analytics
The current version of Filelio does not include Internet access, advertising SDKs, or third-party analytics SDKs. If future versions add network-based services, this Privacy Policy will be updated.

## 8. Data Selling
We do not sell users' personal data or file contents.

## 9. Data Retention and Deletion
Users can remove Filelio's app-specific local data by clearing the app's data in Android settings or uninstalling the app. Permanently deleted files may not be recoverable.

## 10. Children's Privacy
Filelio is a general-purpose utility and is not designed to collect personal information from children.

## 11. Security
Filelio is designed to perform file-management operations locally. Users should keep important files backed up before destructive file operations.

## 12. Changes
This policy may be updated if Filelio's features, permissions, data practices, or legal requirements change.

## 13. Contact
For privacy-related questions, please use the developer contact email published on Filelio's Google Play Store listing.
