# Filelio Privacy Policy — GitHub Pages

Upload these files to a GitHub repository.

## Simplest GitHub Pages setup

1. Create a new public GitHub repository, for example `filelio-privacy`.
2. Upload `index.html` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. After deployment, GitHub will show the public HTTPS URL.
7. Use that public URL in Google Play Console's Privacy Policy field.

`privacy-policy.md` is included as a readable backup/source version.

Important: the policy describes the current Filelio build: no Internet permission, no advertising SDK, and no analytics SDK. If those features are added later, update the policy before publishing the changed app.
