Privacy Policy

Filelio: File Manager

Package: com.filelio.filemanager

Effective date: September 25, 2026

1. Overview

Filelio: File Manager (“Filelio”, “the app”, “we”, “us”, or “our”) is an Android file-management application designed to help users browse, organize, search, copy, move, rename, compress, extract, share, restore, and delete files stored on their device.

The current version of Filelio processes file information locally on the device and does not automatically upload a user's files or file contents to our servers.

2. Information We Collect

The current version of Filelio does not require an account and does not automatically collect or transmit personal information to us. File and storage information used by the app is processed locally to provide file-management features.

Filelio does not include an Internet permission in the current app build, so the app itself does not use a network connection to send files or analytics data to us.

3. File and Storage Access

Filelio's core purpose is file management. To provide this functionality, the app may request broad storage access, including Android's “All files access” permission where supported and permitted by the operating system.

This access is used to perform actions requested by the user, including:

  • Browsing folders and files on shared/internal storage
  • Searching and sorting files
  • Copying and moving files
  • Renaming files and folders
  • Creating folders
  • Creating and extracting ZIP archives
  • Finding large, duplicate, recent, or old files
  • Managing favorites and recent-file references
  • Moving deleted items to Filelio's Recycle Bin and restoring them

Filelio does not use storage access to secretly upload, sell, or commercially profile the user's files.

4. Sharing Files

Filelio includes a user-initiated Share feature. When the user chooses to share a file, Android's system sharing interface (Sharesheet) is opened and the selected file may be provided to the app or service selected by the user.

Any data handling performed by the receiving app or service is governed by that third party's own privacy policy. Filelio does not automatically share files without the user's action.

5. Recycle Bin and Local App Data

Filelio may keep local records required for features such as Favorites, Recents, and Recycle Bin. Recycle Bin items and related metadata remain on the user's device until restored, deleted permanently, removed by the operating system, or the app's data is cleared/uninstalled.

6. Storage Analyzer and Duplicate Finder

Storage Analyzer, large-file detection, old-download detection, and duplicate-file analysis are performed locally on the device. These features may inspect file names, paths, sizes, dates, and file content as necessary to identify duplicates or calculate storage usage. This information is not automatically transmitted to us.

7. Internet, Advertising, and Analytics

The current version of Filelio does not include Internet access, advertising SDKs, or third-party analytics SDKs. If a future version adds online services, advertising, analytics, cloud backup, or other network-based features, this Privacy Policy will be updated before or when those features are released.

8. Data Selling

We do not sell users' personal data or file contents. The current version does not automatically transmit users' files or locally analyzed storage information to us.

9. Data Retention and Deletion

Because the current version stores its operational data locally, users can remove app-specific data by clearing Filelio's app data in Android settings or uninstalling the app. Files that users permanently delete through Filelio may not be recoverable.

Files shared with another app are outside Filelio's control after the user sends them to that app.

10. Children's Privacy

Filelio is a general-purpose utility and is not designed to collect personal information from children. The current version does not require account creation or automatically collect personal information from users.

11. Security

Filelio is designed to perform file-management operations locally. We use reasonable technical safeguards in the app's file operations, but no software or device environment can be guaranteed to be completely secure. Users should keep important files backed up before performing destructive operations such as permanent deletion or moving files.

12. Changes to This Privacy Policy

We may update this Privacy Policy if Filelio's features, permissions, data practices, or legal requirements change. The updated policy will show a revised effective date.

13. Contact

For privacy-related questions about Filelio, please use the developer contact email published on Filelio's Google Play Store listing.
